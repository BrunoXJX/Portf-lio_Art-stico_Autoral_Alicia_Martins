# Portfólio Alicia Martins

Projeto estático em HTML, CSS e JavaScript, organizado em páginas separadas para Home, Sobre Mim, Projetos e Contacto.

## Como abrir

1. Abre a pasta `portfolio-alicia` no Visual Studio Code.
2. Instala a extensão **Live Server** se ainda não tiveres.
3. Clica com o botão direito em `index.html`.
4. Escolhe **Open with Live Server**.

Também podes abrir diretamente o ficheiro `index.html` no navegador.

## Estrutura

```txt
portfolio-alicia/
├── index.html
├── sobre.html
├── projetos.html
├── contacto.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
    └── img/
```

## Onde editar

- Home: `index.html`
- Sobre Mim: `sobre.html`
- Projetos e modal de detalhes: `projetos.html` e `js/main.js`
- Contactos: `contacto.html`
- Projetos, descrições, imagens e competências: `js/main.js`
- Cores, grelha, responsividade e visual: `css/style.css`
- Imagens: `assets/img/`

## Cores usadas

- Preto: `#0D0D0D`
- Cinza profundo: `#1C1C1F`
- Branco suave: `#F4F1EC`
- Pintura: `#8A1F1F`
- Ilustração digital: `#233B73`
- Animação: `#7B8B5A`
